# 3DSpatialAgents
A multi-agent computer vision system that helps users understand 
their surroundings in real time. Uses 3D computer vision to combines object detection with 
3D depth perception to give agents a spatial awareness of the 
user's environment and to describe the environent to the user when prompted.

Built with Gemini-Robotics-ER-1.5, Google ADK (agent framework), 
and Streamlit for prototyping.

How to run locally(tentatively): 
get a Gemini API key from Google AI Studio
clone repo
run streamlit run updatedStreamlit.py
